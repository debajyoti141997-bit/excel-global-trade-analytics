## 📌 Project Overview

This repository contains the complete Excel Analytics exam submission for **Global Traders Consortium**. The project demonstrates end-to-end data processing—from raw data cleaning and cross-workbook lookups to VBA macro creation and an executive performance dashboard.

---

## 📁 Files Included

### 1. Final Exam Submission
* `PGA_38_Excel Exam_Debajyoti Roy.xlsx`: Complete workbook containing answers to Q1 through Q10 across dedicated sheets, including the Trade Performance Dashboard and VBA macros.

### 2. Source Datasets & Documentation
* `Excel_Exam Paper - LMS.docx`: Official exam question paper outlining requirements and marking schemes.
* `Global_Trade_Data.xlsx`: Raw transaction-level trade data.
* `Product_Master.xlsx`: Master lookup table for product unit costs, suppliers, and origin countries[cite: 16].
* `Region_Lookup.xlsx`: Regional mapping table for region names, continents, and manager names[cite: 16].
* `Performance_Data.xlsx`: Monthly aggregated KPI and performance dataset[cite: 16].

## 🛠️ Key Technical Highlights

* **Data Cleaning & Text Parsing (Q1, Q3):** Application of `TRIM`, `PROPER`, customer code generation using `LEFT` and string concatenation, and date/currency formatting[cite: 16].
* **Business Metrics & Classification (Q2, Q4):** Calculated Cost of Goods Sold (COGS), profit margins, summary statistics (`AVERAGE`, `MAX`, `MIN`), and logical nested `IF` performance classifications (`Excellent`, `Good`, `Needs Improvement`)[cite: 16].
* **Cross-Workbook Lookups (Q5):** Combined datasets using `INDEX/MATCH`, `VLOOKUP`, and `IFERROR` error handling[cite: 16].
* **Aggregation & Pivot Tables (Q6, Q7):** Multi-criteria summary reporting using `SUMIFS` and `AVERAGEIFS`, plus interactive PivotTables paired with Slicers[cite: 16].
* **VBA Macro Automation (Q9):** Custom `HighlightTopPerformers` macro assigned to an interactive shape button[cite: 16].
* **Executive Dashboard (Q10):** Interactive dashboard featuring 7 core visuals (Line, Clustered Column, Pie, Bar, Scatter, Doughnut) and KPI summary cards[cite: 16].
